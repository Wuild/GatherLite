# GatherLite 8.4.10

## Display profiles

- The Profiles page now uses WoW's native dropdown for mouse input and groups the controls for switching, copying, deleting, and creating profiles. Gamepad navigation remains available.

## Minimap markers

- Nearby node markers hide within 70 yards by default so you can see the game's live tracking dots. You can change the distance or turn off hiding in Minimap settings. Saved circle and ring modes are preserved.
- Ring mode uses a centered resource icon when a marker is placed on the minimap rim, including on shaped or rotating minimaps.
