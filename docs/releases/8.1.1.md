# GatherLite 8.1.1

## Combined farming routes
- Check multiple herbs, ores, or pools to build one farming circuit, with shared locations counted once.
- Pick a map zone to see its known resources. **Only this zone** is enabled by default; disable it to browse all resources and generate routes across zones.
- Combine search, resource categories, and zone filtering. Saved routes restore selected resources and zone scope after reload.

## Map overlay and browsing
- Moved the selected-resource panel into the map's bottom-right corner, freeing the full sidebar height for resources.
- Route controls remain fixed while panning or zooming, with calculation progress above the panel.
- Combined pins retain each resource's icon and details. Controller navigation includes resource categories and the zone filter.

## Gathering tracking and minimap
- Learned professions set initial map filters while preserving existing manual choices.
- Optional automatic gathering tracking restores learned Find Minerals or Find Herbs outside combat. Selecting Mining or Herbalism sets the preferred mode.
- Added an option to hide nearby nodes when nearby circles are disabled. Nearby distance changes apply immediately.

## Window and controller fixes
- Main-window opening, closing, controller Back, and the world-map action use native panel behavior.
- Controller input remains available when GatherLite owns native panel focus, and focused category icons display their names.
