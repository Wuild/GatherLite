# GatherLite 8.1.0

A feature release for World of Warcraft: Forever.

## World map and routes

- Added native-style breadcrumb navigation with zone dropdowns and an always-open resource sidebar.
- Added optional neighboring-zone gathering nodes to zone maps, disabled by default in World Map settings.
- Added a complete static neighbor inventory for Forever maps and indexed nearby-node lookups.
- Keep gathering nodes off world and continent overviews. Zone nodes do not need reloading while panning or zooming.
- Clear old routes when switching resources, cancel pending calculations, and keep route lines on their own zones.

## Controller support

- Added controller navigation for the main window, breadcrumb dropdowns, resource lists, route actions, and settings.
- Added a visible map cursor with zone selection, edge panning, shoulder-button zoom, and gathering-node tooltips.
- Selecting a resource focuses the route action. Left/Right adjusts focused settings sliders; the right stick scrolls.
- Fixed native world-map controller-cursor tooltips and avoided protected gamepad action-bar calls by using addon-owned input.

## Getting started

- Open the main window on first login with native-style, arrow-anchored help explaining its features.
- Replay the tour with Help or Reset onboarding in Debugging settings.
- Added a configurable key binding to toggle the GatherLite window.
- Show the installed version in the right-aligned footer.
- Added a scrollable What's New tab with mouse and controller support.

## Minimap preferences

- Added Show nearby node circles in Minimap settings, enabled by default. Disable it to keep normal resource icons when close to a node.

## Database and fixes

- Refreshed the predefined gathering database and resource-name aliases.
- Corrected nearby minimap queries for maps with different widths and heights.

Feature releases increment the minor version. Patch releases are reserved for database updates.
