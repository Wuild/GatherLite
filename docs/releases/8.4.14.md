# GatherLite 8.4.14

## Gathering database

- Added 240 gathering locations to the Forever database, bringing the total to 35,933. All previously published locations were retained.

## World map

- Shift-click the GatherLite map button to hide or restore gathering markers while keeping your resource filters.
- OpenMap loads dense views in batches. Individual markers stay aligned and keep their size while you zoom. Use World Map settings to change the default 7× cutoff.
- OpenMap reuses prepared markers when you reopen the same view or zoom back above the cutoff, reducing flicker.

## Minimap

- Adjust ring opacity independently of the resource icons and set an optional custom ring color.
- Turn off GatherLite pin tooltips while keeping markers visible.
- Nearby marker hiding defaults to 150 yards. The upgrade turns hiding back on once for profiles using regular icons and keeps custom distances and ring or circle modes.
