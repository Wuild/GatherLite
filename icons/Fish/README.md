# Fish marker artwork

The inv_misc_*.tga files are transparent derivatives of World of Warcraft item
icons downloaded from Wowhead's image CDN. Original game artwork is by Blizzard
Entertainment. Source URLs and SHA-256 hashes are in tools/wowhead/fish-icons.json.

Regenerate using tools/prepare_fish_icons.py with Pillow. Fishhook.tga is the
existing fishing-pool marker.
